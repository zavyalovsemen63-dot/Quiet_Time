## ✨ О проекте

Режим **«Не беспокоить» (Do Not Disturb)** для умного дома автоматически глушит громкие звуковые уведомления, приглушает освещение, блокирует нежелательные звонки или голосовые анонсы в определенное время суток или при срабатывании определенных триггеров (например, когда кто-то спит или включен ночной режим кино).

## 🚀 Основные возможности

* **Расписание по времени:** Автоматическое включение и выключение режима в заданные часы (например, с 23:00 до 07:00).
* **Контекстные триггеры:** Активация режима, когда ложатся спать (по датчику сна, нажатию кнопки или статусу телефона).
* **Умная фильтрация:** Критически важные уведомления (протечка воды, дым, SOS) всё равно сработают со звуком.
* **Интеграция с освещением:** Плавное уменьшение яркости ландшафтных и внутренних светильников при активации режима.
* **Голосовые ассистенты:** Бесшумный режим для колонок (Яндекс.Станция, Google Home, Apple HomeKit / Home Assistant).

## 📦 Установка

### Для Home Assistant

1. Скопируйте содержимое папки `custom_components` или файлы конфигурации в вашу директорию Home Assistant.
2. Добавьте следующий код в ваш файл `configuration.yaml`:

```yaml
input_boolean:
  dnd_mode:
    name: Режим Не беспокоить
    icon: mdi:do-not-disturb
```

3. Перезагрузите сервер Home Assistant.

## ⚙️ Пример автоматизации (YAML)

```yaml
alias: "DND: Включить ночной режим"
description: "Приглушить звук и свет в 23:00"
trigger:
  - platform: time
    at: "23:00:00"
action:
  - service: input_boolean.turn_on
    target:
      entity_id: input_boolean.dnd_mode
  - service: light.turn_off
    target:
      area_id: гостиная
```
